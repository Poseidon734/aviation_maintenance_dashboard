    Components (URR / MTBUR)

    Part numbers

    • URR and MTBUR use total fleet FH for the period as exposure (one unit of each part number per aircraft assumed).
    • Weibull β: rank regression (Bernard median ranks) on FH between consecutive unscheduled removals of the same part number on the same aircraft. Suspensions (units not yet failed) are not modelled, so β may be biased.
    • β < 0.9 infant mortality · 0.9–1.1 random · > 1.1 wear-out.

    Data quality notes

      KPI definitions and assumptions

      • Departures = Fleet_Avg_Monthly_Departures × active months per aircraft (days between first and last event / 30.4375).
      • Dispatch Reliability % = (departures − technical delays − technical cancellations) / departures × 100. No cancellation field exists, so cancellations = 0.
      • Technical delay = Is_Technical_Delay and Delay_Minutes > 15 (IATA). Rate per 100 or 1,000 departures.
      • URR = unscheduled removals / fleet FH × 1,000. MTBUR = fleet FH / unscheduled removals. Assumes one unit of each part number per aircraft.
      • Flight hours / cycles per period = linear interpolation of cumulative values between events, clipped to the period.
      • Repetitive defect = 3 events of the same ATA on one aircraft within N days or M cycles (1st to 3rd). Overlapping windows are merged into one episode.
      • UCL = mean + k·sigma of monthly defect rate per 1,000 FH (2024 base, months meeting the exposure threshold).
